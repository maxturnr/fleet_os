## 🔧 What's Fixed

### 1. ✅ Split Costs Now Available in "Log a Cost"

**Issue:** Split option wasn't showing when adding new transactions

**Fixed:** 
- Added "🔀 Split across multiple cars" option to Add Transaction modal
- Properly populates dropdown when modal opens
- Resets split state when opening modal
- Full validation and real-time totals work

**How to use:**
1. Click "Log a Cost"
2. Enter total amount
3. Select "🔀 Split across multiple cars"
4. Add cars and amounts
5. Total turns green when it matches
6. Save!

### 2. ✅ Page Remembers Your Tab on Refresh

**Issue:** Refreshing the page always took you back to Dashboard

**Fixed:**
- App now saves which tab you're on to localStorage
- When you refresh, it restores the last tab you were viewing
- Works for all tabs: Dashboard, Owned Stock, SOR, Transactions, P&L, Balance

**How it works:**
- View any tab (e.g., Transactions)
- Refresh the page (F5 or Cmd+R)
- **Stays on Transactions!** ✨
- No more losing your place
